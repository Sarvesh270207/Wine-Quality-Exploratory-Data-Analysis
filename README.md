# Wine Quality Exploratory Data Analysis (EDA)

## Internship Project

This project is part of my Data Analyst Internship at **Unified Mentor**.

The objective of this assignment is to perform Exploratory Data Analysis (EDA) on the Wine Quality Dataset using Python and its data analysis and visualization libraries.

## Project Objectives

- Load and understand the Wine Quality Dataset.
- Explore different features such as fixed acidity, volatile acidity, citric acid, alcohol, and quality.
- Calculate central tendency measures such as Mean, Median, and Mode.
- Analyze data distributions and skewness.
- Visualize numerical features using histograms and boxplots.
- Create Pandas Series to analyze acidity features based on wine quality.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset Description

The Wine Quality Dataset contains information about wine physicochemical properties and their quality ratings.

**Dataset features include:**
- Fixed Acidity
- Volatile Acidity
- Citric Acid
- Residual Sugar
- Chlorides
- Free Sulfur Dioxide
- Total Sulfur Dioxide
- Density
- pH
- Sulphates
- Alcohol
- Quality

## Tasks Performed

### Task 1: Load and Study the Data
- Import the required Python libraries.
- Load the dataset using Pandas.
- Explore dataset structure and features.
- Check missing values and duplicate records.
- Generate descriptive statistics.

### Task 2: Distribution and Central Tendencies
- Analyze the distribution of numerical features.
- Calculate Mean, Median, and Mode.
- Calculate skewness to understand data distribution.
- Create histograms, KDE plots, and boxplots.
- Interpret positive and negative skewness.

### Task 3: Pandas Series for Acid Types
- Create a new Pandas Series containing acidity feature values.
- Calculate average fixed acidity, volatile acidity, and citric acid for a selected wine quality.
- Compare average acidity values across different wine quality levels.
- Visualize the results using bar charts.
